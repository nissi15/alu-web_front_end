# ALU Web Front End

Responsive web design exercises for the Techium website.

## Project structure

- `responsive_design/`: progressive HTML and CSS tasks from the starter files through the completed responsive layout
- `responsive_design/images/`: original and responsive image assets used by the pages

Open any numbered `*-index.html` file in a modern browser to review that stage of the exercise. The final task is available in `responsive_design/10-index.html`.
